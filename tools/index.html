内容生产工具箱

配套「普通人 + AI 从 0 做小红书」系列。
工具开源，克隆仓库即可本地使用。

快速开始

1
git clone 或下载仓库，进入 tools/ 目录
2
运行 bash dev.sh，自动启动本地服务并打开此页
3
点击下方工具卡片开始使用

需要 Python 3（macOS / Linux 通常已内置）。
部分工具调用 AI API（Gemini 等），需在工具内配置 API Key，Key 仅存本机。
直接双击 HTML 文件打开也可使用，但 AI 生图功能可能因浏览器 CORS 限制失效，建议通过 dev.sh 启动。
