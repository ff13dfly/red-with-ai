# 项目（档案 + 进展）

> 这里集中放项目相关的东西。
> - **本文件 = 档案**：每个项目「是什么 / 链接 / 现状 / 能讲什么 / 边界」。
> - **`project/<名>.md` = 进展流水**：各项目的素材源（日期 + git 摘要 + 手动补充 + 💡可写点子）。
> - 流程：进展流水 → 挑 💡 进 `../content/ideas.md` → `../content/drafts/` → `published/`。

## 进展来源（红线）

- **公开项目**（SPP / Septopus / SoloMind / 小说 Aiin）：可拉取 **git 摘要 + 手动补充**。
- **私有项目**（QRrr 完整版、现版 SOLO）：**绝不放原始 git log**（提交信息含未公开功能、内部/商业设计、基础设施等）；**只放你手动给的、能公开的进展**。

只列能公开的部分；未公开的细节不在这里展开。

## A · AI 写科幻小说《隐藏》

- **是什么**：一部从 AI 切入的硬科幻，讲一个 AI 的生存故事。人和 AI 共创。
- **链接**：https://github.com/ff13dfly/Aiin （公开，分步发布设定集）
- **现状**：长篇连载中（12 万字+）；设定集在 GitHub 分步公开。
- **能讲什么**：分工本身就是「AI 做量、人做质」的活教材——
  - **人（质）**：搭整个世界观、各层级设定与关联、逐章人工修改调整。
  - **AI（量）**：补设定细节、梳理时间线、判断每章丰度、写初稿。
  - 设定集分步公开 = 天然的连载内容线：每放出一块世界观/设定就是一篇笔记。
- **边界**：公开**设定集**（分步）与方法/过程，**正文原稿不公开**。

## B · SPP（String Particle Protocol）

- **是什么**：为 AI 设计的「空间语言」——不直接描述几何，用离散单元 + 面连接，靠 collapse 让 3D 结构涌现。
- **链接**：https://github.com/ff13dfly/spp-protocol （公开，CC BY-NC）
- **现状**：核心规范已公开（SPP-Core v1.0）。
- **能讲什么**：为什么给 AI 设计一套空间语言、为什么不直接画几何——原创思路。
- **边界**：聚焦协议思想与公开规范。
- **进展流水**：[SPP.md](./SPP.md)

## C · QRrr 打卡贴 / 资产管理

- **是什么**：基于 QR 码的实体贴纸，贴在物品上扫码记录信息 / 行为，**数据存本地、保护隐私**。
- **链接**：暂无（项目推进中）。
- **现状**：开发 / 推进中。
- **能讲什么**：**功能与解决的问题**——资产管理、习惯打卡、防伪验证等；和用户共创打磨。
- **边界**：**先不公开定价**（主讲功能 / 价值），价格随项目推进再放；**私有项目，不放原始 git log**。

- **链接**：SoloMind（早期版，公开）https://github.com/ff13dfly/SoloMind

- **边界**：只碰 SoloMind 公开版 + 方法；现版 SOLO 细节暂不公开；**不放原始 git log**。
