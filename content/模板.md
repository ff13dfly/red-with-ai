# 小红书笔记模板

> 写新笔记时复制这份到 `drafts/`，文件名用「NNN-线-主题」，如 `drafts/002-C-征集打卡场景.md`。
> 框架固定、照着填。原则：**一篇讲透一个点，正文 150-300 字**。
> 图片存 `content/_assets/NNN/`（本地不入 git）。

---

## 元信息
- 序号：NNN（三位，如 001 002 003，与 _assets/ 子目录对应）
- 线：A / B / C / D（或「元主线」）
- 选题：
- 状态：构思 / 写作 / 待发 / 已发
- 计划发布：YYYY-MM-DD

## 标题（≤20 字，给 2-3 个候选）
- 候选 1：
- 候选 2：
> 钩子方向：痛点 / 反差 / 数字 / 好奇 / 身份认同

## 封面（首图，命门）
- 主文案（一眼能懂的大字）：
- 画面 / 设计说明：
- 竖图 3:4（1080×1440）

## 正文（150-300 字）
**开头**（前两行决定留不留）：
> 钩子：痛点 / 反差 / 提问

**主体**：
> 分点 / 故事 / 步骤，讲透一个点

**结尾**（互动收口）：
> 提问 / 引导评论 / 共创征集 / 轻 CTA
